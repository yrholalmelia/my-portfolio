# Yrholjames Almelia Portfolio

A responsive 3-page portfolio built with semantic HTML5, one external CSS file, and a small shared JavaScript file for mobile navigation.

## Files

- `index.html` — Home
- `skills.html` — Key Skills Inventory + Skill Gaps
- `career-goals.html` — Career Goals + Development Plan
- `styles.css` — Shared visual styles and responsive layout
- `script.js` — Shared mobile navbar interaction

## GitHub Pages deployment

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. Commit and push the files.
4. In GitHub, open **Settings → Pages**.
5. Select **Deploy from a branch**, choose the main branch and `/ (root)`, then save.
6. GitHub Pages will publish the site at your repository's Pages URL.

## Customize before publishing

Update the placeholder email, LinkedIn URL, GitHub URL, profile-photo placeholder, and any skill levels/examples with your final information.
