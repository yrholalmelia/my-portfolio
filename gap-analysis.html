Roadmap for Improvement

Knowing the gaps makes growth more intentional.

A practical comparison between my current skill level and the capabilities I need for my long-term goal of becoming a full-stack developer and software engineer.

Current Position

Strong foundation, growing depth

I already have experience with HTML/CSS, Java, databases, networking, GitHub, documentation, and basic software development. My biggest needs are deeper full-stack experience, cloud deployment, security, and professional teamwork practices.

6 Priority skill gaps
01

Front-End Development

Advanced JavaScript & React

Current: Beginner JavaScript and intermediate HTML/CSS.

Required: Strong component-based development, state management, reusable UI patterns, and modern front-end workflows.

Plan: Follow guided React courses, build component-based applications, and complete 2–3 portfolio projects using JavaScript and React.

Target: 2–3 React portfolio projects

02

Backend Development

APIs, Authentication & Server-Side Programming

Current: Basic programming and beginner SQL/database experience.

Required: Ability to create REST APIs, connect applications to databases, handle authentication, and structure backend services.

Plan: Study a backend framework, build a REST API, practice CRUD operations and authentication, then connect it to a front-end application.

Target: 1 complete full-stack application

03

Cloud & DevOps

Cloud Deployment, CI/CD & Containers

Current: Novice-level cloud fundamentals and GitHub Actions exposure.

Required: Practical deployment, automated testing/builds, containers, environment configuration, and basic monitoring.

Plan: Study cloud fundamentals, practice with AWS or Azure, create a GitHub Actions workflow, and deploy a portfolio or full-stack project.

Target: 1 deployed app + CI/CD workflow

04

Cybersecurity

Secure Coding & Application Security

Current: Beginner security knowledge and basic network-security concepts.

Required: Stronger understanding of common web risks, authentication security, input validation, access control, and network defense.

Plan: Take beginner cybersecurity courses, practice safe coding exercises and lab simulations, and add security checks to personal projects.

Target: 1 security-focused lab/project

05

Collaboration & Professional Practice

Team Workflows, Code Review & Project Management

Current: Teamwork and beginner GitHub collaboration experience.

Required: More consistent branching, pull requests, code reviews, issue tracking, and task planning.

Plan: Use GitHub Projects or Trello in group work, practice pull requests and reviews, and maintain clear issues and documentation.

Target: 2 collaborative projects using a team workflow

06

Data & Databases

Advanced SQL & Data Design

Current: Beginner MySQL and SQL experience.

Required: More confidence with joins, normalization, indexes, transactions, query optimization, and production-oriented database design.

Plan: Practice SQL problem sets, improve relational schema design, build database-backed applications, and document design decisions.

Target: 2 database-backed applications
